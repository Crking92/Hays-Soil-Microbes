# v1.0 location lookup guide

The location lookup page adds:

- clickable Leaflet map
- Kyle/ETJ soil polygon lookup
- browser geolocation
- latitude/longitude lookup
- address search using OpenStreetMap/Nominatim
- plain-language result cards

Browser location is used client-side. The static dashboard does not store location. Address search sends the typed address to OpenStreetMap/Nominatim.

Limitations: SSURGO soil mapping is not a property-level soil test, and microbial interpretation remains inferred/regional analog evidence unless local samples are added.
