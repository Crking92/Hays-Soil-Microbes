# v0.9 beginner-friendly design notes

The public gardener view now uses a benefit-first structure:

1. Explain the main idea before showing data.
2. Define soil microbes and soil functions in plain language.
3. Show practical benefits: nutrients, roots, drought resilience, carbon, structure, plant matching.
4. Treat technical tables as supporting material, not the first thing the user sees.
5. Repeat the core limitation: this is not a yard-specific microbial test.

The research view now includes a clearer what/why/how explanation before the technical tables.
