# v1.2 story-first design

This version changes the dashboard from data-first to teaching-first.

## Main changes

- Gardener view starts with soil food web teaching.
- Function data are translated into plain-language soil-life jobs.
- Dense tables are hidden behind expandable sections.
- Research view explains what/why/how before showing tables.
- Soil records are optional supporting evidence, not the first thing a layperson sees.

## Teaching frame

The dashboard now emphasizes:

- soil is habitat
- plants feed microbes
- microbes recycle organic matter
- soil predators release nutrients
- fungi/roots/organic matter build structure
- soil type shapes the biological community

## Interpretation guardrail

The dashboard can teach likely benefits and regional functional potential, but it should not claim exact local microbial presence without local sampling.
